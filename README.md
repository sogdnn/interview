# Interview App Database

Database schema for an AI-powered interview practice application.

## Tables
- USERS - stores user accounts
- JOB_ROLES - available job roles to practice
- QUESTIONS - interview questions per role
- INTERVIEWS - recorded interview sessions
- ANSWER_ANALYSIS - AI feedback on answers
- ADAPTIVE_ENGINE - adjusts difficulty based on performance
- SKILL_PROGRESS - tracks user skill improvement over time

## How to run
python3 create_tables.py
